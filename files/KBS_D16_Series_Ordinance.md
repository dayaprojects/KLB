## 1. EFE style audit → Kurdish house style

### 1.1 Audit method
Two auditors (series editor + designer) review the current EFE Level 1–4 Course and Practice Books, the Grammar Guide, the Vocabulary Builder and the audio site. They fill in the audit grid below with page references and photos for **internal reference only**. The photos are never reproduced, traced or shared outside the audit team.

### 1.2 Audit grid (pre-filled with expected findings, all `[VERIFY]`)

| Dimension | Expected EFE pattern | Kurdish house-style decision |
|---|---|---|
| Components | Course Book + Practice Book per level (1:1 units); reference titles; free audio via website/app | Same (D15 §1) + Starter, Heritage Fast-Track, Bridge, Teacher's Guides |
| Level mapping | L1–L4 ≈ A1–B2 | L1–L4 = A1–B2; L5 = C1 |

| Exercise formats and numbering | Unit-exercise numbering; skill and audio icons; answer lines; answers at the back; audio cues next to the exercise | Same logic; in-book label `7.3`, data ID `L1-U07-E03` (§4) |
| Page grid | Modular spreads on white; coloured panels; generous white space; one teaching point per panel | 12-column spread grid, **mirrored for RTL** (§3.3) |
| Typography | Clean sans-serif hierarchy; large example sentences; key words highlighted | Kurdish-capable type stack (§3.4) |

| Iconography | Icons for listening, speaking and audio tracks | Own icon set (§3.6) |
| Illustration style | Clean, bright digital illustrations; isolated objects; adult everyday scenes; diverse people | Commissioned in a comparable clean, flat, bright style, with Kurdish and diaspora settings (§3.7) |
| Audio cueing | Audio icon with track or file reference; listen-and-repeat after model sentences | Icon + exercise ID + Hub QR per unit (§6) |
| Review cycle | Periodic review units with mixed exercises | Every 5th unit; level checkpoint in U40 |

### 1.3 Distinctiveness layer (IP risk control, RISK-011)
The **pedagogical form** is emulated closely: rhythm, panel logic, exercise types, rubric style and illustration register. The following stay **distinct** from DK:
- series name and logo;
- cover design;
- primary brand colours and level colours;
- the icon drawings themselves;
- the typefaces;
- every sentence, example, exercise item and illustration.

A legal look-and-feel opinion is required **before the first design brief** (§9).

## 2. Rubric phrasebook (binding wording)

The register is **second-person singular imperative**, friendly and neutral. One action per sentence. Every exercise shows a worked **example** first.

## 3. Visual system

### 3.1 Formats
- Course and Practice Books: 189 × 246 mm `[ASSUMPTION]`, full colour.
- Arabic-script editions are **right-bound** (they open from the right). The Latin edition is left-bound.

### 3.2 Panel types

| Panel | Purpose | Rules |
|---|---|---|
| **Objectives box** | New language · Vocabulary · New skill (three lines) | Top of the first spread of every teaching unit |
| **Presentation scene** | Illustrated context or dialogue | Max 8 speech bubbles; all audio-linked |
| **Key-language panel** | Model sentences with highlighted forms | Max 6 sentences |
| **Formation diagram** | Colour-coded morphology build-up (§3.5) | One structure per diagram; reads in the edition's direction |
| **Vocabulary spread** | Illustrated set with labels + audio IDs | 8–16 items per spread |
| **Exercise panel** | Numbered exercise with icon, rubric, example, items | One exercise per panel; answer lines sized to the script |
| **Culture note** | Sociocultural point (SO items) | ≤ 60 words |
| **Contrast box** | Sorani ↔ Kurmanji note (Bridge-ready) | Optional; ≤ 40 words; shows the other variety in its usual script |
| **Tip box** | Learning tip or common error | ≤ 30 words |

### 3.3 Grid and mirroring
- A 12-column grid per page, with 2-page spreads as the design unit. Outer margin ≥ 15 mm, gutter ≥ 18 mm.
- **RTL mirroring rule:** the whole grid is mirrored for `ckb` and `kmr-Arab`. Reading order, the objectives-box position, exercise numbering flow, illustration facing direction (characters face into the page) and arrows in formation diagrams all reverse.
- **Illustrations are commissioned direction-neutral or in two variants** where direction matters (pointing, reading, queues).

### 3.4 Typography `[VERIFY coverage and shaping before adoption; CON-010]`

| Role | Arabic-script editions | Latin edition |
|---|---|---|
| Body | Naskh-style OFL font with full Kurdish coverage (candidate: Noto Naskh Arabic), 12–13 pt | Humanist sans OFL (candidate: Noto Sans), 10.5–11 pt |
| Example sentences | Same family, 15–16 pt, medium weight | 13–14 pt, medium |
| Headings and UI labels | Sans Arabic OFL (candidates: Noto Sans Arabic, Vazirmatn) | Same sans family, bold |
| Formation diagrams | Sans Arabic, large, with explicit ZWNJ handling | Sans, large |

Arabic-script body text is set **1.5–2 pt larger** than Latin for equal legibility. Diacritics (harakat) are never used. A **glyph test page** is printed with every proof (ڕ ڵ ێ ۆ ڤ ە, ZWNJ joins, and ê î û ç ş).

**Numerals `[DECISION NEEDED — Standards Committees]`:** default is Eastern Arabic-Indic digits in running text in Arabic-script editions and Western digits in the Latin edition. Exercise numbers and IDs use **Western digits in all editions**, so they match the Hub.

### 3.5 Colour system
- **Brand and level colours:** the KBS palette is distinct from DK's (§1.3). L1 to L5 use five distinct hues; covers follow the KBS brand.
- **Morphology colour code** (series-wide, both varieties):

| Element | Colour | Also marked by (colour-blind safety) |
|---|---|---|
| Stem | Dark blue | Solid underline |
| Prefix (e.g., دە- / di-, بـ / bi-) | Orange | Dotted underline |
| Personal ending / copula | Green | Double underline |
| Clitic (Sorani) | Purple | Box outline |
| Ezafe | Red | Small circle marker |
| Oblique / agreement marker (Kurmanji) | Teal | Wavy underline |
| Negation | Grey | Strikethrough-free grey tint |

Every pair must reach a 3:1 contrast ratio against the background, and each element keeps its non-colour marker for accessibility.

### 3.6 Iconography
Own icon set (line icons, rounded): **listen** · **speak** · **read** · **write** · **audio file + ID** · **Hub QR** · **culture** · **contrast** · **tip** · **review**. Icons are direction-neutral or mirrored for RTL.

### 3.7 Illustration brief (binding)
- **Style:** clean, bright, flat-to-semi-flat digital illustration; simple shading; isolated objects on white for vocabulary sets; adult everyday scenes for presentations. The register is comparable to EFE, but **no reference tracing**. Artists receive the house-style sheet, **not** DK pages.
- **People:** adults of varied ages, body types and skin tones. Balanced gender in professional and domestic roles. Clothing ranges from everyday urban to traditional (for festivals) and work clothes. Religious dress appears naturally, without emphasis.
- **Settings:** Erbil, Sulaimani, Duhok, Kirkuk, Amed (Diyarbakır), Qamishli, Mahabad, Sanandaj, Kermanshah, villages and mountains, plus diaspora cities (Berlin, Stockholm, London, Toronto …). Representation rules follow D14 §6.
- **Do not depict:** flags, party symbols, political leaders, maps with contested borders, weapons, or conflict before B2 (D14 §6).
- **Deliverables:** layered vector (SVG/AI) + 600 dpi raster; asset ID per illustration (DR-011); licence assignment to the Institute; alt text written by the author (§7).

| Spread | Content | Panels |
|---|---|---|

| 4 | Freer practice: E06–E07 (speaking with model answer; short writing); optional culture note or contrast box | Exercise ×2 · Culture/Contrast |
| Back matter | Answer key, audio scripts, glossary entries for the unit | — |

- **Size:** 3–4 spreads per teaching unit; review units are 2 spreads.
- **Target study time:** L1 teaching unit 45–60 min (Course) + 20–30 min (Practice) `[ASSUMPTION]`.
- **Rule:** one objective per spread. Every spoken item has audio.

## 10. IP compliance (Path A)

1. **Emulation rule (§2 of the prompt):** match voice, formats, artwork style and page logic. **Never** translate, trace or copy DK text, exercise items or artwork.
2. **Clean-room practice:** authors and illustrators do not work from open DK books. They work from this ordinance, the house-style sheet and the unit brief. Only the audit team handles DK books (§1.1).
3. **Originality check per unit:** automated comparison of English back-glosses of exercise items against a reference list compiled during the audit (themes are allowed; sentence-level matches are flagged). A visual review of illustrations against the audit photo set (no shared compositions). The legal reviewer signs off.
4. **Look-and-feel opinion** before the first design brief, and again before the first print of each title (RISK-011).
5. **Contributor agreements:** assignment or exclusive licence to the Institute; moral-rights handling per jurisdiction `[VERIFY]`; warranty of originality.
6. **Permissions** for literary excerpts (L4+): written permission or public domain, recorded in DR-011 asset licences.
7. **Trademark clearance** for "Pêngav / پێنگاو" in the KRI, Iraq, the EU and the UK before branding (DN-15).
8. **Path B switch:** if DK grants a co-edition licence, this section is replaced by the licence terms, and §1.3 distinctiveness is relaxed only as far as the licence allows.

## 11. Quality gates and pilot (§16.8)

| Gate | Threshold |
|---|---|
| Minimum-curriculum coverage | **100 %** of CUR items for the level mapped to ≥ 1 unit (automated from the content model) |
| Orthography checker | 0 forbidden code points; 0 unresolved glossary inconsistencies |
| Proof error rate (sampled final proof) | ≤ **1 error per 2,000 words** per edition before print `[ASSUMPTION]` |
| Originality | 100 % of units signed off |
| Audio | 100 % of spoken items have audio; IDs resolve; loudness within spec |
| Pilot outcomes (per level) | ≥ 70 % of completers reach the target level on the placement measure (KPI-024); learner satisfaction ≥ 4.0/5; teacher usability ≥ 4.0/5; unit time within ± 20 % of target |
| Accessibility | All images have alt text; EPUB accessibility checks pass |

**Pilot design:**
- Per level, 4–6 adult cohorts (KRI urban, KRI rural or Duhok, diaspora L2 learners, diaspora heritage learners), each of 10–20 learners.
- Placement measure before and after; completion rates; unit-time logs; learner and teacher feedback; observed lessons (Teacher's Guide inputs).
- Revisions happen **before the full print run**. The first print of each title is ≤ 2,000 copies per edition, or print-on-demand (D10 §3.3 levers).
